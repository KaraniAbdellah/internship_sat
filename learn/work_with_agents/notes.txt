How I Work with AI Coding Agents ?
/////////////////////////////////////////////////////////////////////////////
𝗧𝗟;𝗗𝗥:
LLMs are stateless. Output quality depends on context quality.
My workflow starts like this:
👉 First of all I start by knowing what I need to build (Authentication feature). 
👉 I create PLAN.md where I put all details of the feature like (hashtag#Task, hashtag#Rules, hashtag#Instructions, ...)] and then I asked claude or chatgpt for format the file.
👉 I pick the context that the Agent needs (basically files that need to be created or updated, some images for inspiration)
👉 I give Plan.md and Context to the Agents
At the end I verify the implementation test it, and maybe catch some errors.
