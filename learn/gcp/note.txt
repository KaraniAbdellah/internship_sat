// Concepts
/*
    - Artifact Registry: is place where we can put container images, packages, ...
        and centrally this artifacts.

    - Cloud Resouce By Default is Private

    - Google IAM (Identity and Access Management): is tool allows you control access to
        resource within google cloud.
        --> This tool allow admin asign roles to users, service accounts, ...
        --> Components:
            - Identity: The entities that need access to resouces
            - Roles: collection of permission
            - Permission: specific Actions like (Delete, Update, ...)

    - Cloud Run: service for running code, ...
        --> Process HOW:
            - We Can Put Our Container Image in Docker HUB OR Put is Registry Artifact
            - Create Service Cloud RUN and Use Image
            - Get Endpoint
        --> Important:
            - Container Image: A static file containing code, OS, and dependencies.
            - Registry (The Warehouse): Where images are stored (e.g., Docker Hub,
                Google Artifact Registry).
            - Cloud Run Service: A manager waiting with a URL. It does not create the CI; it pulls the CI from
                the warehouse and runs it
        --> We can deploy Code from VSCODE to Cloud
            - gcloud run deploy
                * In process We create Artificat Registry for Cloud Run Pull CI
                * By Default Cloud Run use port 8080 not 8000
    - Service Account: No human Identity we give it to application for Google Cloud resources access.
        - When app Authentificate Service Account. it has access to all resources.
        - NOTE: Each Service Account has roles, so an app that uses that Service Account gets the same permissions.
*/

/*
    1. Create GCP Project
            ↓
    2. Enable required APIs
    - Cloud Run
    - Artifact Registry
    - Cloud Storage (if needed)
            ↓
    3. Install Google Cloud CLI on my machine
            ↓
    4. Authenticate your machine
        gcloud auth login
            ↓
    5. Configure the project
        gcloud config set project PROJECT_ID
            ↓
    6. Create Service Account
        (ONLY if your application needs to access GCP services)
            ↓
    7. Give the Service Account the required IAM roles
        - Storage access
        - Artifact Registry
        - Cloud Run
            ↓
    8. Build & deploy
        gcloud run deploy
*/
